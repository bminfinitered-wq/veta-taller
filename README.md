# Veta Taller · Página de ebanistería

Página de venta de muebles a medida (closets, repisas, cajones, mesas) y línea de tallados.

## Cómo editar
- Todo el contenido está en `index.html` (texto, colores en `:root`, enlaces).
- Las fotos están en la carpeta `img/`. Para cambiar una, sube otra con el mismo nombre.
- WhatsApp: busca `593981193147` y reemplázalo si cambia el número.
- Redes: busca `vetataller` y pon tus usuarios de Instagram, Facebook y Pinterest.
- Nombre del negocio: busca `Veta Taller`.

## Publicar con GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
